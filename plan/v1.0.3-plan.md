## 根因与决策措辞

播放/暂停指示器当前为 `⏸\u{fe0e}` / `▶\u{fe0e}`（`src/ui.rs:18-19`，
`39fd939` 曾尝试用 VS15 变体选择符请求文本呈现）。在目标 Windows 终端
环境（Windows Terminal、旧版 conhost 等）中这两个字符的呈现不可靠，
VS15 未能稳定生效，实测回退为 emoji 形式。为获得跨平台确定性，统一改用
ASCII 指示器，单一代码路径，不做平台分支。

## 改动一：ASCII 播放状态指示器（固定显示宽度）

`src/ui.rs`：

```rust
const PAUSE_ACTION_ICON: &str = "|| ";   // 正在播放（Space 可暂停）
const PLAY_ACTION_ICON: &str = ">  ";    // 已暂停（Space 可继续）

// 非当前行占位: "   "
```

- 三种状态与空占位**均为 3 个显示列**，标题起始列不随播放状态变化而水平

- 改动三的列表列宽模型中 `LIST_ICON_WIDTH = 3`。

测试：

## 改动二：频谱

### 2.1 移除标题文字（`src/ui.rs` `draw_visualizer`）

移除 `Block` 的 `.title(" 频谱 · 50 Hz → 8 kHz ")`，保留 `Borders::TOP`
分隔线。布局高度计算（`BASE_LAYOUT_HEIGHT`/`visualizer_height`）不受影响。

### 2.2 取值改为带内 FFT bin 最大值（`src/app.rs`）

`map_spectrum_frame` 的对数分带不变；把中心频率线性插值
`interpolate_magnitude` 替换为
`band_max_magnitude(frame, bin_width, lower_hz, upper_hz)`。区间一律按
**半开区间**处理，`end` 为 exclusive 并 clamp 到 `frame.len()`，避免
off-by-one 多吃右侧相邻频段的一个 bin：

```
start = floor(lower_hz / bin_width) as usize
end   = ceil(upper_hz / bin_width) as usize, .min(frame.len())
切片  frame[start..end]
取区间内全部有限幅值的 max（dB 域，max 即最响）
```

退化处理：若半开区间为空或区间内无有限值（全 NaN），取带中心频率
`sqrt(lower_hz * upper_hz)` 最近的单个 bin；该 bin 仍非有限则返回
`SPECTRUM_THRESHOLD_DB`。

删除 `interpolate_magnitude`。

### 2.3 dB 映射与响应参数（`src/app.rs`、`src/player.rs`）

- `src/player.rs` `SPECTRUM_THRESHOLD_DB: -60.0 → -72.0`。
  必须同步改：GStreamer spectrum 元素把低于 threshold 的幅值截断为
  threshold，不改则 -72~-60 dB 区间数据不会到达应用层。
- `src/app.rs` `normalize_magnitude`：
  `(db.clamp(FLOOR, CEIL) - FLOOR) / (CEIL - FLOOR)`，其中
  `FLOOR = SPECTRUM_THRESHOLD_DB`（-72，保持单一来源）、新增
  `SPECTRUM_CEIL_DB = -12.0`。
- `VISUALIZER_RESPONSE_GAMMA: 1.6 → 0.75`
- `SPECTRUM_ATTACK: 0.65 → 0.85`
- `SPECTRUM_DECAY: 0.18 → 0.28`
- `VISUALIZER_LOW_FREQUENCY_GAIN: 0.65 → 1.0`（第一轮中性 baseline，
  不做未经验证的保留；若目验低频过强，再调到 0.85~0.9 并复验——见
  “Windows 人工目验门禁”清单第 4 项）

测试（`src/app.rs`）：
- `spectrum_normalization_clamps_invalid_and_out_of_range_values`：
  期望改为新映射（-90→0、-72→0、-42→0.5、-12→1、0→1、NaN→0）；
- `spectrum_mapping_uses_logarithmic_50_to_8000_hz_bars`：
  重写断言——峰值 bin 所在 bar ≈ 1.0（gain=1.0 后旧的 `< 0.75` 断言不再
  成立），远离峰值的 bar = 0；对数位置断言（bass_bar < 8、
  treble_bar > 24）保留；
- 动画测试直接引用 `SPECTRUM_ATTACK/DECAY` 常量，自动适配；
- 新增 band max 单测：半开区间边界（不多吃右邻 bin）、区间内多 bin 取
  最大值、区间为空/全 NaN 时退化到最近单 bin。

## 改动三：歌曲列表动态列 + 显示宽度截断

### 3.1 新依赖

`unicode-width = "0.2"`（MIT/Apache-2.0）。更新 Cargo.toml 与 Cargo.lock
并提交；changelog 依赖段按仓库约定记录；RPM vendor tarball 由
`build-rpm.sh` 的 `cargo vendor --locked` 在构建时自动重建；CI 全部
`--locked` 兜底。

### 3.2 截断函数（`src/ui.rs`）

```rust
/// 按终端显示宽度截断：超出时保留 max_width-1 列内容后接 "…"（宽度 1）。
/// CJK 按 2 列、控制字符按 0 列（unicode-width）。
fn truncate_display(text: &str, max_width: usize) -> String
```

边界：`max_width == 0` → 空；`== 1` 且原文超宽 → `"…"`；原文不超宽原样
返回。

### 3.3 列模型（替换 `draw_library` 行构造）

列序：`icon(3)  title  artist  album  format(6)  duration(W_d)`，
表格式对齐，列间统一 2 空格（取代现有 `·` 串联），duration 右对齐，
其余左对齐。一行永不换行、永不溢出。

常量：

```rust
const LIST_ICON_WIDTH: usize = 3;
const LIST_GAP_WIDTH: usize = 2;
const FORMAT_COLUMN_WIDTH: usize = 6;
const MIN_TITLE_WIDTH: usize = 12;
const MIN_ARTIST_WIDTH: usize = 8;
const MIN_ALBUM_WIDTH: usize = 8;
const HIGHLIGHT_SYMBOL_WIDTH: usize = 2; // "▸ "
```

ratatui 0.30.2 的 List 在存在选中项时为**所有行**预留 highlight symbol
宽度（源码核实：ratatui-widgets 0.3.2 `list/rendering.rs`，未选中行填充
等宽空格），故可用宽度：

```
usable = area.width - 2(边框) - 2(highlight)
```

### 3.4 分档阈值由最小列宽推导（不硬编码）

```
min_row_width(列集合) = LIST_ICON_WIDTH + Σ 各列最小/固定宽
                        + LIST_GAP_WIDTH × (列数 - 1)
tiers = [全列, 隐藏格式, 再隐藏专辑, 仅标题+时长]
选第一个满足 min_row_width(tier) <= usable 的 tier
```

推导参考值（时长列 5 时）：全列 50，隐藏格式 42，隐藏专辑 32，
仅标题+时长 22。代码中只存常量与推导函数，不写死 84/66/48 之类阈值。

### 3.5 可变列宽度分配

可变区 `R = usable - icon - duration - gaps`。先满足各列最小宽，剩余空间
按比例分配（3 列：标题 45 / 歌手 30 / 专辑 25；2 列：60 / 40），小数向下
取整，余数归标题（最高优先级）。

分配后**所有列都必经 `truncate_display` + pad**，固定宽列也不例外：
可变列截到各自分配宽；`format` 截到 `FORMAT_COLUMN_WIDTH` 再 pad 到 6
（防止 "MPEG-4 AAC" 之类超长 metadata 打破固定列模型）；`duration` 宽度
按缓存的 `W_d` 构造保证不超限，右对齐 pad。

### 3.6 时长列宽缓存（禁止每帧扫描）

`App` 新增字段 `duration_column_width: u16`：

- `App::new` 初始化为 5（`"--:--"` / `"59:59"` 宽度）；
- `apply_scan_finished` 中重算一次：
  `max(5, 全部曲目 fmt_duration(duration) 的最大显示宽度)`
  （≥1 小时 → 7，≥10 小时 → 8，以此类推；只在扫描结果应用时计算，
  绘制路径零扫描）。

`self.tracks` 仅在这两处赋值（已核实），缓存不会失效。

### 3.7 now-playing 行顺手一致性

`draw_now_playing` 的标题/歌手**先组成 "标题 — 歌手" 一个整体**，按
`top[0].width − LIST_ICON_WIDTH(3)` 的预算截断整串，再前置固定宽度
指示器——整行保证 ≤ `top[0].width`。仅对标题、歌手各自独立截断的做法
在两者都偏长时拼起来仍会溢出，不可用。

实现按前缀预算分配（与整串截断数学等价，同时保留样式分段）：

```
budget = top[0].width - LIST_ICON_WIDTH
若标题显示宽度 ≤ budget：标题完整；剩余预算交给 " — 歌手" 段做
                         truncate_display
否则：truncate_display(标题, budget)，歌手段整体舍弃
```

样式保持标题 bold primary、歌手 muted；`top[1]` 右侧状态栏不受影响。

测试（`src/ui.rs`、`src/app.rs`）：
- 截断：ASCII、纯 CJK（"你好世界" 截 5 → "你好…"）、中英混排、等宽不截、
  宽度 0/1 边界；
- 分档选择：用推导函数的边界值断言 tier（不断言硬编码数字）；
- 行宽不变量：构造超长 CJK 标题/歌手，各 tier 下渲染行显示宽度 ≤ usable；
- 时长列宽缓存：apply_scan_finished 后含 ≥1h 曲目时为 7，否则 5；
- format 列截断：超长格式串（如 "MPEG-4 AAC"）截到 6 列后 pad；
- now-playing 截断：标题本身超宽（歌手段舍弃）、标题放下但歌手被截、
  恰好等宽三种情形，整行宽度 ≤ `top[0].width − indicator`。

## 改动四：ASCII 播放进度条

`src/ui.rs` `draw_now_playing` 中 `Gauge` 替换为单行 Paragraph：

```
 01:28 ============>---------- 03:27
```

```rust
/// width 列 ASCII 进度条：'=' 已播放、'>' 播放头、'-' 未播放。
fn ascii_progress_bar(ratio: f64, width: usize) -> String
// width == 0 → ""
// ratio >= 1.0 → "=" * width（100% 全 '='，末尾不留 '>'）
// 否则 filled = floor(ratio * width) ∈ 0..=width-1
//      "=" * filled + ">" + "-" * (width - filled - 1)
```

- 渲染：左 `fmt_duration(position)` + 空格 + bar + 空格 +
  右 `fmt_duration(duration)`；bar 宽 = 内宽 − 两标签宽 − 2（saturating）。
- 超过一小时由 `fmt_duration` 自然扩展（`1:02:03`），标签变长 bar 自动
  缩短。
- 时长未知：ratio=0，右标签 `--:--`（与现状一致）。
- 样式：标签 muted，bar primary；移除 `Gauge` import。

测试：宽度不变量、字符集合法（仅 `=`、`>`、`-`）、ratio=0 / 0.5 / 1.0
（1.0 全 `=`）、width 0/1 边界。

## Windows 人工目验门禁（tag 前必须完成）

Release 不得作为首次验证。目验包来源（二选一）：

- 功能分支 CI 的 `windows-packages-ci` artifact（`if: always()` 保留
  Portable ZIP 与 Installer）；或
- 本地 Windows 构建。

目验清单：

1. Windows Terminal 与旧版 conhost（如可用）：播放/暂停指示器为 ASCII
   `||` / `>`；播放状态切换时标题不水平跳动；
2. 长中文标题/歌手以 `…` 截断，单行不溢出；收窄窗口时列逐级收缩
   （隐藏格式 → 隐藏专辑 → 仅标题+时长）；
3. 进度条纯 ASCII，超一小时曲目标签正常扩展，播到 100% 时全 `=`；
4. 频谱观感：安静时压得住、鼓点冲得起；若低频过强，把
   `VISUALIZER_LOW_FREQUENCY_GAIN` 调到 0.85~0.9 复验后固化取值。

目验通过后才允许打 tag。
