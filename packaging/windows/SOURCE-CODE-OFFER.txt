=====================================================

third-party-licenses\LGPL-2.1.txt).

Precise source references for GStreamer 1.28.6
----------------------------------------------
The complete corresponding machine-readable source code of the
GStreamer 1.28.6 binaries in this package is the source of the
following exact revisions:

- GStreamer monorepo source archive, tag 1.28.6 (contains all
  GStreamer modules built into the runtime):
  https://gitlab.freedesktop.org/gstreamer/gstreamer/-/archive/1.28.6/gstreamer-1.28.6.tar.bz2

- GStreamer release tag browser:
  https://gitlab.freedesktop.org/gstreamer/gstreamer/-/tags/1.28.6

- Per-module release tarballs:
  https://gstreamer.freedesktop.org/src/gstreamer/gstreamer-1.28.6.tar.xz
  (sibling modules of the same 1.28.6 release, e.g. gst-plugins-base,
  gst-plugins-good, gst-plugins-bad, are published in the same
  directory layout under https://gstreamer.freedesktop.org/src/)

- Cerbero build recipes, tag 1.28.6 (defines the exact package and
  dependency versions used to produce the official runtime installer
  this package redistributes):
  https://gitlab.freedesktop.org/gstreamer/cerbero/-/archive/1.28.6/cerbero-1.28.6.tar.bz2
  https://gitlab.freedesktop.org/gstreamer/cerbero/-/tree/1.28.6
